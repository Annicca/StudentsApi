# Примеры к двум презентациям React

Учебный проект на JavaScript и Vite. Все примеры видны на одной странице и работают независимо.

## Запуск

Установите Node.js 22.22+ или актуальную 24 LTS. Распакуйте архив и откройте терминал в папке react-examples.

```bash
npm install
npm run dev
```

После запуска основная витрина доступна по `/`, а законченный пример React Router — по `/router`.

## Пример React Router

Пример из третьей презентации собран как небольшой магазин. В нём показаны:

- `BrowserRouter`, `Routes` и `Route`;
- `Link`, `NavLink` и программный переход через `useNavigate`;
- общая оболочка с `Outlet` и вложенными маршрутами;
- динамический адрес `/router/products/:id` и `useParams`;
- отдельная обработка неизвестного маршрута и отсутствующего товара.

Для проверки откройте каталог, карточку товара, кнопки браузера «Назад» и «Вперёд», а также адреса `/router/unknown` и `/router/products/999`.

Откройте адрес Local из терминала. Консоль и вкладка Network доступны в инструментах разработчика браузера.

## Сборка

```bash
npm run build
npm run preview
```

API /api/products обслуживается учебным middleware Vite и работает в dev и preview. Это демонстрационный сервер, не полноценный backend. При отдельном размещении dist нужно подключить собственный API.

| 1 | 20 | `ExpressionsExample.jsx` | Выражения внутри JSX |
| 2 | 4 | `ClickExample.jsx` | Обработчик события |
| 2 | 5 | `VariableCounter.jsx` | Обычная переменная |

| 2 | 11 | `BatchCounter.jsx` | Два обновления значением |
| 2 | 12 | `FunctionalCounter.jsx` | Два обновления функцией |
| 2 | 13 | `ObjectCounter.jsx` | Обновление объекта |
| 2 | 14 | `ProductList.jsx` | Список и key |
| 2 | 15 | `LifecycleExample.jsx` | Монтирование и размонтирование |
| 2 | 17 | `ApiProductList.jsx` | Пример работы useEffect |

Фрагменты слайдов дополнены минимальным JSX для запуска. Версии CartCounter и ProductList сохранены под разными именами. LifecycleExample — дополнительная демонстрация теории слайда 15. Пример для домашнего задания BookCard не включён, чтобы не подменять самостоятельную работу готовым решением.

VariableCounter намеренно не обновляет надпись. ClickExample и SnapshotCounter выводят результат в консоль. Две карточки со слайда 10 намеренно одинаковые. StrictMode не подключён: учебная демонстрация эффекта выполняется без дополнительного проверочного цикла разработки. Пример эффекта повторяет краткий код презентации; обработка ошибок и отмена запроса в компоненте здесь не рассматриваются.

В архив не входят node_modules и dist. package-lock.json фиксирует зависимости.
